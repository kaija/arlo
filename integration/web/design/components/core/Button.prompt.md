Pill-shaped button in the three treatments the Arlo sites use.

```jsx
<Button variant="primary" href="#projects">Explore the projects</Button>
<Button variant="secondary" href="https://github.com/kaija"><GitHubIcon size={20} /> View on GitHub</Button>
<Button size="sm" href="https://github.com/kaija"><GitHubIcon /> GitHub</Button>
```

Primary hovers to #4745B5 with an accent glow shadow; secondary/sm hover to the tertiary background. Icons sit inline with an 8px gap.
