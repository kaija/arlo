Badge — read-only state (build status, plan, count). Not interactive.

```jsx
<Badge tone="success" dot>Running</Badge>
<Badge tone="neutral">v0.4.2</Badge>
<Badge tone="solid">New</Badge>
```

- `Badge` = state the system reports. `Tag` = a label the user attached. `Pill` = mono technical metadata. Don't mix them.
- Keep to one or two words; never a sentence.
